## 第1条（本サービスの内容）

1. 本サービスは、ユーザーが音声で回答した内容をAIが評価し、言語化能力の診断・フィードバック・トレーニングを提供するアプリケーションです。
2. 本サービスの一部機能は、有料の月額または年額のサブスクリプション（以下「有料プラン」といいます）に登録することで利用できます。
3. 本サービスの利用にはインターネット接続が必要です。通信料はユーザーの負担となります。

5. 外部認証サービス（Apple 等）を利用する場合、当該サービスの利用規約もあわせて適用されます。
6. 未成年者が本サービスを利用する場合は、親権者等法定代理人の同意を得た上で利用するものとします。

1. 本サービスは、その性質上、ユーザーが録音した音声およびその文字起こしテキストを、AIによる文字起こしおよび評価のために外部のAI事業者に送信して処理します。
